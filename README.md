# 白紙六法：自動題庫

這個專案每 6 小時自動執行一次，做三件事：

1. 照考選部官方的「考畢試題連結網址」清單，下載試題和答案 PDF。
2. 拆成一題一題、對上答案（有更正答案就用更正版）、標出題目裡的法條。
3. 檢查沒問題的試卷才上架到題庫網站，讀書系統打開時會自動抓。

**答案怎麼確認是對的？** 每份試卷上架前，程式會確認答案檔和試題是同一份：年度要相同、試題代號要對得上（答案檔沒印代號時改比科目名稱）、題號要一一對上、答案字母不能超出選項。對不上就不上架。讀書系統裡每題答完都有「試題 PDF／答案 PDF」連結，可以直接對照考選部原檔。

第一次要把 101 年以來約 3.8 萬份試卷全部抓完，為了不造成考選部網站負擔，每次下載間隔 1 秒，**大約需要 2～3 天**。之後只會抓新公布的試卷，幾秒鐘就跑完。

## 一次性設定（約 10 分鐘）

### 1. 註冊 GitHub 帳號
到 https://github.com 免費註冊。

### 2. 建立專案
登入後按右上角 **＋ → New repository**：
- Repository name：`study-system`
- 選 **Public**（公開專案才能免費使用自動排程和網站）
- 按 **Create repository**

### 3. 上傳檔案
在新專案頁面按 **uploading an existing file**，把這個資料夾裡的下列項目**整個拖進去**：
`tools`、`data`、`laws`、`docs`、`README.md`
等上傳完成後，按下方的 **Commit changes**。

### 4. 建立自動排程檔
資料夾名稱開頭有「.」的檔案，網頁上傳常常會被略過，所以這個檔案用手動建立：
1. 在專案首頁按 **Add file → Create new file**
2. 檔名欄位輸入：`.github/workflows/update-exams.yml`（打到 `/` 時會自動變成資料夾，這是正常的）
3. 用記事本打開這個資料夾裡的 `設定用/update-exams.yml`，全部複製，貼到大的輸入框
4. 按 **Commit changes**

### 5. 開啟網站（GitHub Pages）
**Settings → Pages**：
- Source 選 **Deploy from a branch**
- Branch 選 **main**，資料夾選 **/docs**，按 **Save**

幾分鐘後，網站就會出現在：`https://你的帳號.github.io/study-system/`
（這就是線上版的讀書系統，手機也能開。）

### 6. 第一次手動執行
**Actions** 分頁 → 如果出現提示，先按綠色按鈕啟用 → 左邊點 **更新考古題題庫** → 右邊 **Run workflow**。
之後每 6 小時會自動執行，不用再管它。

### 7. 讓電腦上的讀書系統連到題庫
打開你電腦上的 `白紙六法.html` → **設定** → **題庫網址** 填：
`https://你的帳號.github.io/study-system/exams/`
按儲存。（用線上版的話不用填，會自動連。）

## 選用：讓清單也自動更新
考選部的清單每次考試後會增加新的試卷。設定一次下載連結，排程就會自動拿最新清單：
1. 到政府資料開放平台的資料集頁面（https://data.gov.tw/dataset/170565），在 CSV 下載按鈕上**按右鍵 → 複製連結網址**
2. 專案的 **Settings → Secrets and variables → Actions → Variables → New repository variable**
3. Name 填 `CSV_URL`，Value 貼上剛剛的連結，儲存

沒設定的話，就沿用目前這份清單（到 115 年為止）。

## 法規自動更新
另一個排程 `.github/workflows/update-laws.yml` 每週一凌晨從全國法規資料庫下載最新的法律資料，放到 `docs/laws/`。
讀書系統有連網路時會自己去比對：
- 有修正的法規自動換成新條文（沒網路時用檔案內建的版本）
- 筆記裡引用的條文如果文字被修改，引用處會出現 ⚠，提醒你回頭檢查筆記
- 法條頁會列出「最近修正的法規」

設定方式跟考古題排程一樣：**Add file → Create new file**，檔名輸入 `.github/workflows/update-laws.yml`，內容貼上 `設定用/update-laws.yml`，按 Commit changes。然後到 Actions 手動執行一次 **更新法規**。

### 法規更新失敗時
如果 Actions 顯示「下載不到法規資料」，代表法務部網站擋住了 GitHub 的伺服器。備案：
1. 自己用瀏覽器打開 https://law.moj.gov.tw/api/ch/law/json ，會下載一個 zip
2. 把檔名改成 `ChLaw.zip`，上傳到專案的 `data/` 資料夾
3. 再執行一次 **更新法規**（之後每次要更新，就重複這幾步）

## 看執行結果
- **Actions** 分頁：每次執行的紀錄，綠色勾勾表示成功。
- `docs/exams/report.md`：本次成功幾份、失敗幾份、失敗原因。
- 失敗的試卷（例如年代較久的掃描檔）不會上架。把 `report.md` 給 Claude 看，修好解析程式後再重跑。
- 加了新的檢查時，已上架的試卷會在沒有新試卷要抓的空檔慢慢重新檢查；沒通過的會自動下架，列在 `report.md` 的「重新檢查後下架」。

## 「考過幾次」怎麼算
每一條法條的次數＝**明文**（題目或選項寫出「第幾條」）＋**推定**（題目沒寫條號，但題幹加上正確答案的文字跟這一條很像）。
推定用 3,000 題有寫條號的題目驗證過，估計正確率約九成以上；只考觀念、沒有引用條文文字的題目不會算進來，所以實際考到的次數只會更多。
法條頁的目錄會用顏色深淺標出各章節的考試熱度。

## 法條頁的其他功能
- **新修法 × 常考**：法務部資料裡的「沿革」記錄每次修法改了哪幾條（`build_laws.py` 會解析），跟考過幾次對照，列出近兩年修正又常考的條文。
- **我的缺漏**：目錄可以切換成「我的缺漏」，標出常考但你還沒做過、或做錯過的條文和章節。
- **白紙默寫**：條文頁、章節頁按「白紙默寫」，期間、數字、得／應／不得會挖空，點一下看答案。
- **依章節刷題**：點進目錄的某一章，可以一次練這一章考過的所有題目。

## 列印
「列印」頁可以印出（每頁有頁碼，一律黑白友善，跟畫面選的風格無關）：
- **考前筆記**：把你收的考點、題目筆記、錯過的條文依法典順序整理成一本，附錯題、整理筆記和「常考但還沒碰過」的提醒。考前一天印這本。
- **法典・考試熱度版**：整部法或某一章，每條標出考過幾次、近兩年修正，附上你的筆記。
- **默寫卷**：條文的期間、數字、得／應挖空，最後附解答。
- **錯題卷**：錯題本印成考卷，最後附答案和你的筆記。
- 康乃爾筆記、背誦卡、法條整理表（依你的整理筆記）。

## 選用：只收法律科目
在 `.github/workflows/update-exams.yml` 的 `exam_pipeline.py` 那一行最後加上 ` --only-law`，題庫就只保留法律科目（行政法、民法、法學知識、各種法規…），其他科目的試卷檔會被移除。

## 資料來源與授權
- 試題：考選部考畢試題。依著作權法第 9 條，依法令舉行之考試試題不得為著作權之標的。
- 法規：全國法規資料庫（https://law.moj.gov.tw/），依政府資料開放授權條款-第1版利用。
- 內容僅供學習參考，以官方公布為準。

## 檔案說明
| 檔案 | 用途 |
|---|---|
| `tools/exam_pipeline.py` | 抓題主程式（可中斷續跑） |
| `tools/parse_exam.py` | 解析單份試題／答案 PDF |
| `tools/build_laws.py` | 把全國法規資料庫的資料（API 下載的 zip 或 FalV.xml）轉成法規資料，並解析沿革（每次修了哪幾條） |
| `tools/infer_articles.py` | 推定「這題在考哪一條」（題目沒寫條號時，用正確答案的文字比對條文） |
| `tools/build_single.py` | 打包成單一 HTML 檔 |
| `data/ExamQandA_Csv.csv.gz` | 考選部官方清單（壓縮檔） |
| `laws/index.json` | 法規目錄（辨識題目中的法條用，法規排程會自動更新） |
| `docs/laws/` | 自動產生的法規資料（不要手動修改） |
| `docs/index.html` | 線上版讀書系統 |
| `docs/exams/` | 自動產生的題庫（不要手動修改）；`artfreq.json` 是每條法條考過幾次 |
